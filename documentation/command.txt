1. STANDALONE CHART CLI (txcore.visualization.chart_cli)
--------------------------------------------------------------------------------

A. Basic Chart Recreation (Fetches from TradingView & Opens in Browser):
   python -m txcore.visualization.chart_cli --pair EUR/USD
   python -m txcore.visualization.chart_cli --pair GBP/USD
   python -m txcore.visualization.chart_cli --pair USD/JPY
   python -m txcore.visualization.chart_cli --pair AUD/USD

B. Offline / Cached Chart Recreation (Zero API calls, Uses SQLite cache):
   python -m txcore.visualization.chart_cli --pair EUR/USD --from-cache
   python -m txcore.visualization.chart_cli --pair GBP/USD --from-cache

C. Send HTML Chart Directly to Telegram via CLI:
   python -m txcore.visualization.chart_cli --pair EUR/USD --send-telegram
   python -m txcore.visualization.chart_cli --pair EUR/USD --from-cache --send-telegram
   python -m txcore.visualization.chart_cli --pair GBP/USD --from-cache --no-open --send-telegram

D. Run Verification Test Signal (Instant Local Chart Creation + Telegram Text & File):
   python -m txcore.visualization.chart_cli --test-signal
   python -m txcore.visualization.chart_cli --pair GBP/USD --test-signal
   python -m txcore.visualization.chart_cli --pair EUR/USD --test-signal

E. Pattern Audit in Terminal (Prints all detected patterns & reasons):
   python -m txcore.visualization.chart_cli --audit EUR/USD
   python -m txcore.visualization.chart_cli --audit GBP/USD
   python -m txcore.visualization.chart_cli --audit EUR/USD --from-cache

F. Custom Bar Lookback (Default is 180 bars):
   python -m txcore.visualization.chart_cli --pair EUR/USD --bars 300
   python -m txcore.visualization.chart_cli --pair GBP/USD --bars 60

G. Silent Generation (Saves HTML without opening browser automatically):
   python -m txcore.visualization.chart_cli --pair EUR/USD --no-open
   python -m txcore.visualization.chart_cli --pair EUR/USD --bars 300 --no-open

H. List All 19 Supported Currency Pairs:
   python -m txcore.visualization.chart_cli --list-pairs

   # Test and evaluate strategy on past dates for a stock:

   # Test on Index over past time window:
   python run_algotrade.py --name "NiftyBacktest" --index NIFTY --start-date 2026-09-20 --end-date 2026-09-26 --evaluate --no-open

   # Parallel multi-stock backtest evaluation:
   python run_algotrade.py --name "PortfolioBacktest" --stock "RELIANCE,TCS,INFY" --start-date 2026-09-20 --end-date 2026-09-26 --evaluate --no-open

   # Direct CLI historical evaluation with custom risk:reward ratio:
   python -m txcore.cli --stock RELIANCE --start-date 2026-09-01 --end-date 2026-09-25 --evaluate --risk-reward 2.0 --chart --no-open

5. COMMAND-LINE OPTIONS REFERENCE
--------------------------------------------------------------------------------

Option            Description
------            -----------
--pair            Forex currency pair to process (e.g. EUR/USD, GBP/USD, USD/JPY).

--stock           Indian equity stock symbol(s) to extract (e.g. RELIANCE, TCS,
                  or comma-separated "RELIANCE,TCS"). Normalizes exchange automatically.

--index           Indian market index symbol(s) to extract (e.g. NIFTY, BANKNIFTY,
                  or comma-separated "NIFTY,BANKNIFTY").

--symbol,         Generic target symbol(s) for any market (e.g. EUR/USD,
--symbols         or comma-separated "EUR/USD,GBP/USD").

--start-date,     Start date/time for past data fetching & historical evaluation
--from-date       (e.g. "2026-09-01", "2026-09-20 09:15:00").

--end-date,       End date/time for past data fetching & historical evaluation
--to-date         (e.g. "2026-09-25", "2026-09-26 15:30:00").

--evaluate,       Executes historical strategy walk-forward backtest and produces
--backtest        win-rate %, total return %, profit factor, and trade log.

--risk-reward     Risk-to-reward ratio for trade target calculation in strategy
                  evaluation (default: 1.5).

--timeframe, -t   Candlestick timeframe interval for extraction.
                  Options: 1m, 3m, 5m, 15m, 1h, 1d. (Default: 5m).

--bars, -b        Number of lookback candles to fetch. (Default: 30 or 50 bars).

--chart           Generates interactive TradingView HTML chart for the specified
                  pair, stock, or index (opens in browser unless --no-open).

--trend           Analyzes trend structure, EMAs, Support & Resistance distances.

--audit           Runs a terminal-based pattern audit for the specified asset.
                  Displays all detected engulfing, piercing, and dark cloud
                  patterns, key S/R levels, and rule breakdown reasons.

--scan-signal     Evaluates the strategy engine on recent completed bars and
                  outputs confirmed actionable entry signals.

--scan-watchlist  Batch scans monitored Indian stocks & indices for signals.

--snapshot, -s    Displays live Indian market report (Session state, VIX,
                  Market Breadth, Core Benchmarks, Top Movers).

--breadth         Displays live Advances, Declines, Unchanged counts, Advance-
                  Decline Ratio (ADR), and market sentiment.

--sectors         Displays all Indian sectoral indices ranked by performance.

--csv             Optional file path to export extracted DataFrame as a CSV file.

--send-telegram   Uploads and sends the generated interactive HTML chart file
                  or signal alert text directly to Telegram.

--no-open         Generates the HTML chart file in charts/ folder but does not
                  automatically launch your web browser.

--list-pairs      Prints the 19 monitored Forex currency pairs.
