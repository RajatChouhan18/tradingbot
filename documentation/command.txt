This document lists all execution commands, command-line arguments, and feature
toggles for running Bot Version 3, recreating charts, and inspecting past data.

1. STANDALONE CHART RECREATOR (chart_recreator.py)
--------------------------------------------------------------------------------

A. Basic Chart Recreation (Fetches from TradingView & Opens in Browser):
   python chart_recreator.py --pair EUR/USD
   python chart_recreator.py --pair GBP/USD
   python chart_recreator.py --pair USD/JPY
   python chart_recreator.py --pair AUD/USD

B. Offline / Cached Chart Recreation (Zero API calls, Uses SQLite cache):
   python chart_recreator.py --pair EUR/USD --from-cache
   python chart_recreator.py --pair GBP/USD --from-cache

C. Send HTML Chart Directly to Telegram via CLI:
   python chart_recreator.py --pair EUR/USD --send-telegram
   python chart_recreator.py --pair EUR/USD --from-cache --send-telegram
   python chart_recreator.py --pair GBP/USD --from-cache --no-open --send-telegram

D. Run Verification Test Signal (Instant Local Chart Creation + Telegram Text & File):
   python chart_recreator.py --test-signal
   python chart_recreator.py --pair GBP/USD --test-signal
   python chart_recreator.py --pair EUR/USD --test-signal

E. Pattern Audit in Terminal (Prints all detected patterns & reasons):
   python chart_recreator.py --audit EUR/USD
   python chart_recreator.py --audit GBP/USD
   python chart_recreator.py --audit EUR/USD --from-cache

F. Custom Bar Lookback (Default is 180 bars):
   python chart_recreator.py --pair EUR/USD --bars 300
   python chart_recreator.py --pair GBP/USD --bars 60

G. Silent Generation (Saves HTML without opening browser automatically):
   python chart_recreator.py --pair EUR/USD --no-open
   python chart_recreator.py --pair EUR/USD --bars 300 --no-open

H. List All 19 Supported Currency Pairs:
   python chart_recreator.py --list-pairs

3. COMMAND-LINE OPTIONS REFERENCE
--------------------------------------------------------------------------------

Option            Description
------            -----------
--pair            Currency pair to process (e.g. EUR/USD, GBP/USD, USD/JPY).
                  Works across both chart_recreator.py and bot script.

--chart           Alias for --pair.

--auto-charts     Continuously generates/updates local HTML charts in charts/
                  for all 19 pairs on every scan cycle without browser popup.

--verbose         Prints detailed status line for each monitored pair during
                  every scanning cycle.

--from-cache      Loads historical candles and pre-computed patterns directly
                  from the local SQLite database (data/market_cache.db).
                  Does NOT make any API calls to TradingView.

--send-telegram   Uploads and sends the generated interactive HTML chart file
                  directly to your Telegram chat/channel as a document.

--test-signal     Runs an immediate simulated signal execution testing file logging,
                  Telegram text alert, local chart generation, and chart Telegram upload.

--audit           Runs a terminal-based pattern audit for the specified pair.
                  Displays all detected engulfing, piercing, and dark cloud
                  patterns, key S/R levels, and rule breakdown reasons.

--bars            Number of 1-minute historical candles to fetch/load.
                  Default: 180 bars (3 hours of 1-minute data).

--no-open         Generates the HTML chart file in charts/ folder but does not
                  automatically launch your web browser.

--list-pairs      Prints the 19 monitored Forex currency pairs.

   - Database file:     data/market_cache.db
